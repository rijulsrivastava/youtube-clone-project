<h1>Youtube Clone Project</h1>
<p>In this project MERN(MongoDb,Express,REACT,NODE) stack, mongoose, jsonwebtoken , bcrypt, tailwindcss are used used
</p>

<h1>Objectives of this project are:</h1>
<ol>
    <li>To build Youtube clone using MERN stack</li>
    <li>To incorporate new user registeration and login feature</li>
    <li>To use JWT based authentication and authorization to access certain fetures such as like/dislike feature</li>
    <li>To implement error handling</li>
    <li>To use MongoDB for storing data</li>
    <li>To incorporate CRUD operations for videos</li>
    <li>To incorporate CRUD operations for comments</li>
    <li>To add filter videos based on category or search text</li>
    <li>To make application responsive</li>
    <li>To integrate frontend with backend using axios</li>
    <li>To create and manage channel by verified user</li>
</ol>

<h1>Tech stack used:</h1>
<ul>
    <li>REACT</li>
    <li>Tailwind</li>
    <li>CORS</li>
    <li>Axios</li>
    <li>NodeJS</li>
    <li>ExpressJS</li>
    <li>Mongoose</li>
    <li>MongoDB</li>
    <li>jsonwebtoken</li>
</ul>

<h1>How to deploy and run this application</h1>
<ul>
    <li>Open terminal</li>
    <li>How to clone the application: git clone
        https://github.com/rijulsrivastava/youtube-clone-project.git</li>
    <li>run command: cd YoutubeCloneProject</li>
    <li>run command: cd BACKEND</li>
    <li>run command: npm install</li>
    <li>run command: npm start</li>
    <li>Open new terminal</li>
    <li>run command: cd FRONTEND</li>
    <li>run command: npm install</li>
    <li>run command: npm run dev</li>
</ul>
